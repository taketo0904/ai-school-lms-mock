# AIスクール LMS — 画面モック

オンラインスクール向けLMS（学習管理システム）のUIモックです。**HTML1ファイルのみ**で動きます。サーバー不要、ビルド不要。

👉 **デモ:** https://taketo0904.github.io/ai-school-lms-mock/

> これはUIの検討用モックです。表示されているデータはすべてサンプルで、実在の受講生・実績ではありません。

## 構成

3つの領域があります。左上の「ユーザー／運営」で切り替えます。

### 1. eラーニング（受講生）

| 画面 | 内容 |
|---|---|
| マイダッシュボード | 続きから再開・自分の課題・カテゴリ別の進捗 |
| コース一覧 | サムネイル付きのコースカード。絞り込み（受講中／未着手／修了／お気に入り） |
| コース詳細 | コース概要・進捗・レッスンカードのグリッド |
| レッスン視聴 | 動画枠・目次・課題チェックリスト・前後移動 |

コースは「AIスキル（初級／中級／上級）」と「実践コース」の2軸で辿れます。サイドバーからはツール別でも辿れます。

**実践コース**は、営業とマーケがそれぞれ無料編／有料編に分かれています。

| | 無料編 | 有料編 |
|---|---|---|
| 営業 | LinkedInプロフィール・無料営業、Facebook、フォーム営業、紹介 | Sales Navigator、交流会、展示会の逆営業、テレアポ・手紙 |
| マーケ | 全体像、アクセス解析、コンテンツSEO、ホワイトペーパー、ステップメール、X発信、事例、LP | 広告チャネルの使い分け、リスティング、Meta広告、LP最適化、縦型動画 |

このほかに「副業・案件獲得」（クラウドワークス／Wantedly／YOUTRUST など）があります。

### 2. コーチング（タスク管理＋議事録）

タスク管理はJiraのようなUIを、個人向けに絞った作りにしています。

| タブ | 内容 |
|---|---|
| ボード | 未着手／進行中／レビュー待ち／完了の4列。**カードをドラッグして状態を動かせます** |
| 工程 | 6つの工程と到達条件。各工程に関連コースが紐づきます |
| 議事録 | セッションの記録。**アクションアイテムを最上部**に配置 |
| 課題一覧 | 自分の課題／コーチの課題に分けた一覧 |

カードを押すと課題詳細（担当・優先度・期限・親工程・決まった経緯）が開きます。

### 3. 運営（管理者）

| 画面 | 内容 |
|---|---|
| 運営ダッシュボード | サマリー指標と活動グラフ |
| eラーニング視聴状況 | アカウント別の視聴時間・完了レッスン・最終ログイン。**詳細から「何の動画をどこまで見たか」**が見られます |
| コーチングタスク消化率 | 全体／受講生別／工程別の消化率と期限超過 |
| 受講生一覧・学習活動履歴・コース別学習量 | 一覧とログ |
| コーチング管理 | 議事録を書いて課題を配信するフォーム |
| メールテンプレート | 通知メールの編集（タグ挿入つき） |

## 触りかた

1. 上のデモURLを開く（インストール不要）
2. 「コーチング → ボード」でカードをドラッグしてみる
3. 「議事録」からセッションを開く
4. 左上の「運営」に切り替えて「eラーニング視聴状況 → 詳細」を開く

## 実装メモ

- 依存ライブラリなし。HTML／CSS／素のJavaScriptのみ
- ライト／ダークの両テーマに対応（OSの設定に追従）
- 進捗・課題の状態・お気に入りは `localStorage` に保存されるので、閉じても続きから触れます
- レッスン視聴中は `←` `→` で移動、`Esc` で一覧に戻ります
- スマートフォン幅ではサイドバーがドロワーになります

### 状態をリセットしたい場合

ブラウザの開発者コンソールで次を実行してリロードしてください。

```js
localStorage.removeItem("dojo-lms-v1"); location.reload();
```
